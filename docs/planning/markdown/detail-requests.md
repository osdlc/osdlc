# Detail requests

When someone looking at the ecosystem asks for more detail about a package, we write it down here.
A request can mean the package's README doesn't explain enough, or that only our summary of it was
too thin. Each entry says which, and what we changed.

The README explains the problem, when not to use it, how it compares, and how the two checks work. | The explorer's one-line purpose was too thin.
