The profile is called claims. The folder is `profiles/claims/`, the npm package is
`@osdlc/corpus-profile-claims` and the root-file prefix is `claims`. "Claims" is the plain word for
statements backed by evidence. It doesn't clash with a type name, as "evidence" would. "va-spec"
would read as genomics to anyone outside that field.
