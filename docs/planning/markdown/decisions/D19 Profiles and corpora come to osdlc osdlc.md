title: Profiles and corpora come to osdlc/osdlc
status: decided
decided: "2026-11-12"
---

This supersedes [D17](D17%20Profiles%20and%20corpora%20live%20in%20osdlc%20models.md) on where
things live. It follows the repository decision
[D-SM4K](https://github.com/osdlc/osdlc/blob/main/docs/decisions/D-SM4K-markdown-ecosystem-home.md).

- The markdown ecosystem stays in osdlc/osdlc: the Markdown libraries, the corpus-schema spec,
  validator and suite, this plan and the examples. osdlc/markdown's content is folded back in.
- osdlc/markdown and osdlc/models are holding pens. Each keeps a README that says the work happens
  in osdlc/osdlc for now. A library or model that nears 1.0 may move out to them later.
- The profiles (`@osdlc/corpus-profile-sdlc`, `@osdlc/corpus-profile-claims`) and the starter
  corpus (`@osdlc/corpus-sdlc-starter`) come to osdlc/osdlc, not osdlc/models. Their place there
  is not decided. The proposal is `packages/profiles/*` and `packages/corpora/*`. The npm names do
  not change.
- Nothing moves out of sksizer/dev yet. model-schema, the packs and dev's markdown packages stay
  there. The sdlc profile is still regenerated by hand in dev and copied in.
- markdown-store stays in sksizer/rust-ontogen for now.
- osdlc/marketplace stays the plugin marketplace.

The rest of D17 still holds. The claims profile is a general starting profile and sits beside the
sdlc profile. Research corpora live in their own project's repo and extend the claims profile from
npm. Shared types are authored as packs, the type folders of a shared profile are generated, and
each type's schema stands alone.
