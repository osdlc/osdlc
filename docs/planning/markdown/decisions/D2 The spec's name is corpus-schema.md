---
title: "The spec's name is corpus-schema"
status: decided
decided: "2026-11-08"
---

The spec's name is corpus-schema. The package is `@osdlc/corpus-schema`, the command is
`corpus-schema`, and the root file is `corpus-schema.md` (or `.yaml`, `.json`). It says what the
spec adds: a schema on top of a corpus. A level-0 corpus simply has no schema file.
