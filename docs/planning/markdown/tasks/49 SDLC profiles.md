Generate `@osdlc/corpus-profile-sdlc` from the intent and sdlc packs. For now it is one profile that
holds both packs' kinds. A separate intent profile can split out later, if a consumer needs the
intent kinds alone. It was built in
[osdlc/markdown#19](https://github.com/osdlc/markdown/pull/19), and task 78 brought it to
osdlc/osdlc, at `packages/profiles/sdlc/`, before its first publish ([D19](../decisions/D19%20Profiles%20and%20corpora%20come%20to%20osdlc%20osdlc.md)), because it is shared now and dev is private. It is not published yet (task 61). The generator stays in dev, so until task 62 the profile is regenerated by hand: run the
generator in dev and copy its output in. A closed type needs flattened `x-extends` to see its
parent's fields. Its refs are ids and wikilinks, some to several types. After 48, 44, 45 and 46.
