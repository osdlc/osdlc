# osdlc site

The documentation site and blog, built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build), published to GitHub Pages at
https://osdlc.github.io/osdlc/ by `.github/workflows/site.yml` on each push to
`main`.

## Run it

`site/` is not part of the packages workspace, so install it on its own:

```sh
pnpm install                       # the packages workspace, from the repo root
cd site
pnpm install --ignore-workspace
pnpm run dev       # http://localhost:4321/osdlc/
pnpm run build     # into dist/
pnpm run api       # API reference into public/api (needs cargo); before build
```

## Where the content comes from

- **Standards** are written in `../standards/` and copied in by
  `scripts/sync-standards.mjs` before every `dev` and `build`. Edit the files
  in `standards/`, never the copies under `src/content/docs/standards/`
  (they are not committed).
- **Libraries** get a page each under `/libraries/ts/` and `/libraries/rust/`,
  made by `scripts/sync-libraries.mjs` from each package's manifest and
  README. A TypeScript package and a Rust crate with the same directory name
  are paired as twins. The overview at `/libraries/` lists them side by side.
- **Library guides**: a package with a `docs/guide/` folder gets those pages
  published under its library page, in the sidebar under the library's name.
  They are markdown or MDX. An MDX page may import a Vue component from beside
  it, and the component may import the library as `@osdlc/<name>`, which
  resolves to the package's source. `packages/ts/intersect/docs/guide/` is the
  example.
- **Apps**: a package listed in `APPS` in `scripts/sync-libraries.mjs` gets
  its own section at `/<name>/` instead of a guide under its library page.
  The landing page is built from parts of its README, and its runner table
  from the README `APPS` names. The guide pages and screenshots are copied
  in. wayfinder is the one app.
- **API reference** is generated by `scripts/build-api.mjs`: rustdoc for the
  crates at `/api/rust/<crate>/` and TypeDoc for the packages at
  `/api/ts/<name>/`. Without it the library pages build, but their API links
  404 locally.
- **Blog posts** are markdown files in `src/content/docs/blog/`, each with a
  `title`, `date` and `authors` in its frontmatter. Authors are listed in
  `astro.config.mjs`.
- **Other pages** go in `src/content/docs/`.
