# Favor deterministic over probabilistic judgement

## Statement

When a rule, check, schema, script or test can decide something, let it decide. Keep model or
human judgement for what cannot be reduced to a rule.

## Why

A deterministic decision is repeatable and testable. It is cheap to run again, it can be audited,
and it is the same for every reader.

Probabilistic judgement varies from run to run. Its mistakes are hard to see.

## How it applies

- Turn a judgement that keeps coming back into a deterministic check.
- Have agents call deterministic tools, such as CLI verbs and validators, instead of working the
  answer out again.
- When judgement is needed, make its input and output explicit, so a check can verify the result.
- Prefer a validator to a review comment for anything a validator can catch.
