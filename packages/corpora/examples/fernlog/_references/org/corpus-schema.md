# Org principles

An example of an organisation's principles, kept as a corpus. Each
[principle](principles/principles.schema.md) is one record. Project corpora extend this corpus
under `extends` and cite its principles from their own records.

The principles:

- [Prefer standard locations](principles/Prefer%20standard%20locations.md)
- [Back claims with evidence](principles/Back%20claims%20with%20evidence.md)
- [Write decisions down](principles/Write%20decisions%20down.md)

The fernlog project corpus, beside this one in `examples/`, extends it.
