Cursor is an AI code editor forked from VS Code. It keeps a VS Code-style user-data directory (settings, cached data and a local agent-chat database that can reach many gigabytes) plus ~/.cursor, which holds extensions and Cursor-managed agent worktrees.

## Open

- in use: No Cursor source names its process names or lock files; the help only says to fully quit Cursor and force-quit remaining processes.
