Docker Engine (dockerd, built from the open-source Moby project) runs containers on Linux and Windows; Docker Desktop is a proprietary app that runs the engine in a Linux VM on macOS, Windows and Linux. It fills disks with images, stopped containers, build cache and volumes, kept under the daemon's data-root or, with Docker Desktop, inside one large VM disk image file.
