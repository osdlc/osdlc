LM Studio is a desktop app (and headless daemon, llmster) for downloading and running local LLMs (GGUF via llama.cpp, MLX on Apple Silicon). Its models directory, laid out publisher/model like Hugging Face, holds multi-GB model files. The app is closed source; its lms CLI is MIT-licensed.
