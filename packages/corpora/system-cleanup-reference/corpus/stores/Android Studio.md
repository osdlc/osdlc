Android Studio is Google's IDE for Android, built on IntelliJ IDEA. Each major version keeps its own versioned system (caches and indices), plugins and log directories, and it drives the Gradle cache and the Android SDK, which grow large.

## Open

- in use: No Android developer page names the Android Studio process or a lock file in its system directory.
