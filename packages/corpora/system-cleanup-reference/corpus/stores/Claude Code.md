Claude Code is Anthropic's agentic coding tool for the terminal. Its native installer keeps versioned binaries under ~/.local/share/claude/versions and prunes old ones itself; ~/.claude holds session transcripts, file-history snapshots, caches and logs, which are user data.

## Open

- inventory command: No inventory command for versions or stored data is documented; claude doctor is described only for launcher and update problems.
- in use: Which process names or lock files show a Claude Code version or session is in use is not documented on the pages read.
