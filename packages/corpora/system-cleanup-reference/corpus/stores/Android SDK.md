The Android SDK is Google's set of platforms, build tools, emulator and system images for building Android apps. Disks fill with system images and other SDK packages under the SDK directory and with Android Virtual Devices (AVDs) under ~/.android/avd, which are mostly very large disk images.

## Open

- in use: No source documents lock files or processes marking an AVD or SDK package as in use.
