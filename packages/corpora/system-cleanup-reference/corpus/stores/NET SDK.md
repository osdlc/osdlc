The .NET SDK is Microsoft's toolchain for building C#, F# and Visual Basic projects with the dotnet CLI. It fills disks with installed SDKs, runtimes and workloads, and every project gets its own bin and obj build-output folders; NuGet package caches are covered by the NuGet store.
