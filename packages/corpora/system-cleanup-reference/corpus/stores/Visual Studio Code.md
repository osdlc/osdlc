Visual Studio Code is Microsoft's code editor, built on the MIT-licensed Code - OSS repository (Microsoft's own builds ship under a proprietary product license). It fills disks with installed extensions, per-workspace storage, downloaded extension packages, logs and Electron caches in its user data directory.

## Open

- in use: Which process names or lock files mark the user data directory as in use is not documented on the pages read.
