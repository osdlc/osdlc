Disable or move the package cache - Visual Studio (Windows) (https://learn.microsoft.com/en-us/visualstudio/install/disable-or-move-the-package-cache) says, under Disable the package cache:

> Any operation you do on a product will remove any existing packages for that product and will avoid saving any packages after they're installed.
