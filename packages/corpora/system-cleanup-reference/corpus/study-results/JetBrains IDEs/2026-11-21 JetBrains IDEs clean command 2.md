Invalidate caches IntelliJ IDEA Documentation (https://www.jetbrains.com/help/idea/invalidate-caches.html) says, under Invalidate caches:

> When you invalidate the cache, IntelliJ IDEA removes the cache files for all projects ever run in the current version of the IDE.
