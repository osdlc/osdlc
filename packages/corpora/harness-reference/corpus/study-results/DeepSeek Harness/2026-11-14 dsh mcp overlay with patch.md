> Pass one overlay to DSH: ```sh dsh web --patch "$PWD/apps/cli/config/examples/mcp-memory/memorix.cordis.yml" ``` Replace the filename with `mcp-reference-memory.cordis.yml` or `engram.cordis.yml`. The path may point to a copied file anywhere on disk. No memory server is present in the shipped composition, so omitting `--patch` keeps all three disabled.
