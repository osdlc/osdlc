> --effort Set the effort level for the current session. Options: low, medium, high, xhigh, max, or ultracode. Available levels depend on the model. ultracode requests xhigh effort with ultracode turned on, and requires Claude Code v2.1.203 or later. On the main conversation’s model, overrides the modelSettings and effortLevel settings for this session and doesn’t persist
