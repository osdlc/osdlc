> Claude Code refuses a command name or a frontmatter name that contains characters such as these: A zero-width space or a control character A private-use or unassigned character, such as a glyph from an icon font A character that changes the direction of the text around it A blank other than one plain space between words, such as a no-break space, two spaces in a row, or a space at the start or end < or >
