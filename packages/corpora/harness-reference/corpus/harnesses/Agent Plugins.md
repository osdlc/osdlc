Agent Plugins is a cross-vendor plugin format covering skills and MCP only, kept by maintainers from
Amazon, Cursor, Microsoft, OpenAI and Vercel. It is a standard, not a product. Its repository
licenses schemas and software under Apache-2.0 and the specification text under CC-BY-4.0, per its
LICENSE.md. Its releases are semver.
