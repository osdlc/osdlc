Amp is a coding agent from Amp Frontier Corporation, the company its terms of service name. It runs
as `amp` in a terminal and on the web, with mobile apps alongside. Amp publishes no source or
license, so it is recorded as not open source. The CLI's builds are numbered
`0.0.<number>-g<commit>`, such as 0.0.1794643233-g7a2d30, in the vendor's version file, on npm
(`@ampcode/cli`) and in the Homebrew tap. The number reads as the build's Unix time. The spelling
is valid semver, so `versioning` is `semver`; several builds are published a day.
