Grok Build is a terminal coding agent with a fullscreen TUI, started with `grok`. Its repository and
license name SpaceXAI as the maker; the docs are on docs.x.ai. The public repository is synced from
an internal monorepo and takes no outside contributions. It has no GitHub releases. Versions are
semver, such as 1.0.45: the crates carry the number and the repository keeps a changelog with one
file per version.
