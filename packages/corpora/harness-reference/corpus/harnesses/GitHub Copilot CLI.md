GitHub Copilot CLI is GitHub's coding agent for the terminal, started with `copilot`. Its GitHub
repository is public but holds the README, install script and changelog, not the source. It ships
under the proprietary GitHub Copilot CLI License. Releases are semver, such as v1.0.106-9.
