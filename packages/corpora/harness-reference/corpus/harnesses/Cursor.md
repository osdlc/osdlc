Cursor is an AI code editor and coding agent from Anysphere. It also has a CLI and a web agent. The
CLI docs start it with `agent`, while the homepage demo still shows `cursor-agent`. Cursor publishes
no source or license, so it is recorded as not open source. Its main changelog entries carry dates but no
version numbers. The CLI changelog heads each entry with a date stamp, such as v2026.10.22, which
is not the `YYYY-MM-DD` spelling that `date` versioning needs here, and the main changelog gives
the editor's releases no numbers, so `versioning` stays `unknown`.
