Antigravity is Google's agent platform, made of a desktop app, a CLI started with `agy`, an IDE and
an SDK. Google moved free and Google AI Pro/Ultra users from Gemini CLI to Antigravity CLI on
2026-06-18. Google publishes no source or license for it, so it is recorded as not open source: the public
`google-antigravity/antigravity-cli` repository holds the README, the changelog and examples, and
its releases. Each part is numbered as semver, such as CLI 1.5.9.
