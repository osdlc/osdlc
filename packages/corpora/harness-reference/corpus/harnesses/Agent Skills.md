Agent Skills is the SKILL.md folder standard published at agentskills.io. It is a standard, not a
product: harnesses follow it, and its frontmatter limits are the baseline their columns compare
against. The site shows no release numbers, so versions are spelled as dates. The repository's
license is Apache-2.0 by its GitHub metadata.
