# Harness reference, beta

A cited record of coding-agent harnesses, in the shape of the
[claims profile](https://github.com/osdlc/markdown/pull/6): what each harness is, and claims about
how it behaves, each with the evidence behind it.

- [Harnesses](harnesses/harnesses.schema.md): one note per harness, such as
  [Claude Code](harnesses/Claude%20Code.md) or [Gemini CLI](harnesses/Gemini%20CLI.md).
- [Documents](documents/documents.schema.md): one note per page we can point at, grouped by
  publisher.
- [Methods](methods/methods.schema.md): one note per probe, a run anyone can repeat.
- [Study results](study-results/study-results.schema.md): one note per observation: what a document
  said or a run found, and when we looked.
- [Subjects](subjects/subjects.schema.md): one note per question asked of every harness, with the
  shape of its answer.
- [Statements](statements/statements.schema.md): one note per claim about a harness and a subject,
  with its evidence lines and its verdict.
