# Harness reference, beta

A cited record of coding-agent harnesses: one note per harness, named after the product. Each note
says what the harness is, who makes it and where it runs, and lists the vendor pages that back every
value.

Start with [the harnesses](harnesses/harnesses.schema.md), which lists the fields. For example, see
[Claude Code](harnesses/Claude%20Code.md) or [Gemini CLI](harnesses/Gemini%20CLI.md).
