# Harness reference, beta

A cited record of coding-agent harnesses: one note per harness, named after the product. Each note
says what the harness is, who makes it and where it runs, and links to the pages that back every
value.

- [Harnesses](harnesses/harnesses.schema.md): one note per harness, such as
  [Claude Code](harnesses/Claude%20Code.md) or [Gemini CLI](harnesses/Gemini%20CLI.md).
- [References](references/references.schema.md): one note per web page, grouped by publisher.
- [Evidence](evidence/evidence.schema.md): one note per observation of a harness: what a page said,
  and when we looked.
