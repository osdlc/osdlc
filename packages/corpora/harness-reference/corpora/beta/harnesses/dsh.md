DeepSeek Harness is DeepSeek's open-source, plugin-based agent harness, in preview. The `dsh`
command launches it (`dsh web` starts the web UI), and a desktop app is offered for macOS and
Windows. Its release tags are semver with a `dsh-v` prefix, such as dsh-v0.2.2-rc.1.
