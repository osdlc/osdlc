Antigravity is Google's agent platform, made of a desktop app, a CLI started with `agy`, an IDE and
an SDK. Google moved free and Google AI Pro/Ultra users from Gemini CLI to Antigravity CLI on
2026-06-18. Google publishes no source or license for it, so it is recorded as not open source. Its
changelog numbers each part as semver, such as CLI v1.4.12.
