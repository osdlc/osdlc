Kiro is a spec-driven coding agent built and operated by AWS. It comes as a desktop IDE based on
Code OSS, a CLI and a browser agent. From CLI 3.0.0 (2026-11-03) the CLI is a single standalone
`kiro-cli` binary. Its GitHub repository holds issues only, so it is recorded as not open source.
Releases are semver, such as CLI 3.0.0 and IDE 1.4.62.
