Gemini CLI is Google's open-source terminal agent, started with `gemini`, with a VS Code companion
extension. On 2026-06-18 Google replaced it with Antigravity CLI for free and Google AI Pro/Ultra
users. It is still released and maintained for Gemini Code Assist Standard and Enterprise customers,
so its status stays `current`. Releases are semver, such as v0.67.0.
