Claude Code is Anthropic's coding agent. It starts as `claude` in a terminal, and also runs in VS
Code and JetBrains IDEs, in a desktop app and on the web. Its GitHub repository is public but holds
plugins, examples and the changelog, not the source, and its license reserves all rights. Releases
are numbered as semver, such as 2.1.318.
