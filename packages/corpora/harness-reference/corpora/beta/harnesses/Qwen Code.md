Qwen Code is the Qwen team's open-source coding agent, started with `qwen`. It began as a fork of
Gemini CLI v0.8.2 and stopped syncing with it from Qwen Code v0.1. It also has IDE plugins, a
desktop app and an experimental web UI (`qwen serve`). Releases are semver, such as v0.26.7.
