Codex CLI is OpenAI's open-source coding agent for the terminal, started with `codex`. OpenAI also
ships Codex as an IDE extension, a desktop app (`codex app`) and Codex Web; this entry covers the
CLI. Its docs moved from developers.openai.com to learn.chatgpt.com, which the old URL now redirects
to. Release tags are semver with a `rust-v` prefix, such as rust-v0.168.0-alpha.3.
