goose is an open-source, general-purpose AI agent with a desktop app and a CLI started with `goose`.
Its docs say it is part of the Linux Foundation's Agentic AI Foundation, and its repository now
lives under `aaif-goose`. Its Homebrew formula is still named `block-goose-cli`. Releases are
semver, such as v1.57.0.
