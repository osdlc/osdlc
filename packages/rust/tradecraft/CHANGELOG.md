## [0.3.5] - Unreleased

First public release. A command-line tool that reads a vault of markdown skill notes and publishes
or builds them into the formats of several coding-agent tools (Claude Code, Codex, Cursor and Pi),
with drift checks and commands to author and reorganise the vault. Install it with
`cargo install tradecraft`.

### Changed

- The tool is named Tradecraft. The crate and the binary are `tradecraft`, and help text,
  `--version` and error messages say `tradecraft`.
- On-disk and environment names use `tradecraft`: the project file `tradecraft.yaml`, the machine
  file `<config-home>/tradecraft/config.yaml` and `TRADECRAFT_MACHINE_CONFIG`, the `tc-`
  frontmatter keys, `.tradecraft/manifest.json` in each destination, the `.tradecraft-stage` build
  folder and the `Generated by tradecraft` marker.
- The machine file and the `adopt --from-git` checkout cache are found with `tiered-dirs` 0.3
  directly, under the vendor folder `dev.osdlc` (the cache folder is `dev.osdlc.tradecraft`).
  The `TRADECRAFT_ROOT`, `TRADECRAFT_<HOME>_DIR`, `TRADECRAFT_SCRATCH_DIR`,
  `TRADECRAFT_CONVENTION` and `TRADECRAFT_REQUIRE_OVERRIDE` variables move the base directories.
- A vault that has `agent-pants.yaml` and no `tradecraft.yaml` is an error that says to rename the
  file and change its `ap-` keys to `tc-`. A destination that has `.agent-pants/manifest.json` and
  no `.tradecraft/manifest.json` is an error that says to rename the folder.
- Configuration loading uses `config-layers` 0.7. A path in a config file that starts `~user/` is
  no longer expanded, and resolves as a relative path.
- Git runs through `typed-git` 0.4, renames through `markdown-relink` 0.1, and path checks through
  `path-guard` 0.3, all published crates.

### Known limitations

- Windows is not supported yet. The tool builds there, but its tests are not run on Windows.
