# D-06: Licence

## Decision

The package is licensed `MIT OR Apache-2.0`, at the user's option. It ships
`LICENSE-MIT` and `LICENSE-APACHE`. The copyright holder is `sksizer`.

## Why

It matches the crates it is built from and the other libraries in this
repository other than the shared configs and `command-seam`. Before this
release the package was MIT only.

## Consequences

A contribution is accepted under both licences.
