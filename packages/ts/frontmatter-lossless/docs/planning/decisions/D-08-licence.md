# D-08: Licence

## Decision

The package is licensed `MIT OR Apache-2.0`, at the user's option. It ships
`LICENSE-MIT` and `LICENSE-APACHE`. The copyright holder is `sksizer`.

## Why

It matches the Rust twin and the other libraries in this repository other
than the shared configs and `command-seam`. The dual licence is the Rust
ecosystem's default and is accepted by npm users. Before this release the
package was MIT only.

## Consequences

A contribution is accepted under both licences.
