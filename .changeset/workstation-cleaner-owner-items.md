Close the remaining review items. A plan is now version 3: it records each descriptor behind the plugins it ran (`descriptors`: name, source, path and sha256), and `clean --plan` refuses (exit 2, sweep again) when one of them is replaced, edited or no longer loaded, or when a plugin the plan's candidates belong to is now a descriptor it does not record; a version 2 plan is refused as any other version is. A plan and its receipt keep the setup's warnings (a descriptor left out, a config not read) and the packages that did not load. New exports: `agentHistoryDefinition`, `FOLDER_UNREADABLE`, `OLLAMA_UNREACHABLE`, `VAR_FILE_LIMIT_BYTES`, `DescriptorRecordSchema` and `DescriptorRecord`. A folder whose idle time cannot be read, such as one with a folder in it that gives EACCES, is now listed and refused `folder-unreadable` by the `cargo`, `node` and descriptor plugins instead of giving no row. An Ollama that cannot be reached in `object` is refused `ollama-unreachable`, not `ollama-ps-failed`. A descriptor command argument that is an absolute path not built from `{path}`, such as `[rm, -rf, '{path}', /]`, is refused. A descriptor `file` source over 1 MiB gives its variable no value, with no later source tried, and an `env` source of an `XDG_*` folder that is not absolute gives none, as the built-in. On Linux, mount options that cannot be read make the `toolchains` plugin propose nothing for that folder, with a warning. Docker's build cache is labelled `rebuild`. `config` lists only the descriptor parts whose threshold is not the `idleHours` setting. The `vscode` and `cursor` plugins treat a `HOME` that is not absolute as no home. The podman example gives `podman info` 20 seconds.
