First public release. Opens an interactive coding-agent session (`claude`, `codex`, `cursor`, `pi`, `opencode`, `antigravity`) in the terminal app, multiplexer or editor a person already uses: the caller's own terminal, tmux, WezTerm, cmux, herdr, Orca, otty, VS Code or a JetBrains IDE. One host contract in optional parts (`session`, `terminal`, `send`, `find`, `focus`, `capture`, `close`, `openWorkspace`); `requirePart` returns the part or throws `HostPartMissing`. `hostRegistry({ runtimeDir })` builds every host, and hosts that keep state keep it under that directory. Every shell-out goes through an injected `@osdlc/command-seam` runner. The `vscode` and `jetbrains` hosts, their companion plumbing, the tmux attach helpers and `hostCanWait` are experimental. Compared with the unpublished 0.7.0, the tmux session name, the otty title tag and the session-pane file name now end in a hash of the session id, and WezTerm keeps one `spawned/<paneId>.json` per pane instead of `panes.json`; a session opened by an earlier build is not found by `send`, `find` or `close`. The versions before 0.7.1 were never published; the history in this file rebuilds them from the git history.
