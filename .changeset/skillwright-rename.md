The core now writes the names of the `skillwright` CLI. The default frontmatter namespace is `sw` (`sw-kind`, `sw-targets`, …), the manifest is `.skillwright/manifest.json`, and generated files carry `Generated by skillwright`. Under the default namespace a note with a `tc-*` key is refused with its `sw-*` spelling, and a destination with only `.tradecraft/manifest.json` is refused with a rename hint.
