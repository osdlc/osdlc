The plugin contract for the first version: every hook may return a promise and runs under a time limit with its own `ctx.signal`, so `survey`, `recheck`, `clean` and the command line's `main` now return promises; each plugin is one `definePlugin` value holding its settings schema (its own refinements kept) and factory, with the shipped ones in `BUILT_IN_PLUGINS`, whose order is the run order (replacing `PLUGIN_ORDER` and `orderPlugins`); and a candidate is a path or a ref with no folder (git's branches and Orca's records), where a path, whatever the plugin, must sit inside its owner's roots, a target, or a linked worktree of a repository a target is in or whose main checkout is inside a target (so with `~/dev` as the target, a worktree of a repository in `~/dev` is inside wherever it is), checked on real paths at the survey, right before `delete` and in `kit.remove`, with plans at version 2 (a plan of another version is refused: sweep again), `~` for the home folder in ids, and no run as root; and a candidate may say what deleting it costs (`costDescription`: `re-download`, `rebuild` or `lost`), where `lost` is held and needs `--allow discard-user-data`, and `status` shows the cost; and two candidates with the same id or the same real path are one, the first plugin's, while a path candidate with others inside it requires them, so they go first, and one that does not run (refused, spared, held or not allowed) keeps the outer one too, which is then blocked with a reason naming that candidate and what would let it run (`--allow <code>`, `--pick <id>`, or that it is refused or spared) in the clean preview, the `clean -i` checklist and the receipt; and `create` gets the plugin kit, the safety helpers `cargo` and `node` are now built on (`idle`, `size`, `running`, `onPath`, `candidate`, `run` and `remove`), which the core binds each run to the plugin's roots and the targets, so `kit.remove` takes only the path and an unbound kit removes nothing, where idle time counts in fractions of an hour (`idleHours: 0.5` is half an hour) and a folder whose idle time cannot be measured within the time budget is proposed `unmeasured` and needs `--allow unmeasured`, and artifact evidence no longer holds the newest modification time or the size; and git's `delete` refuses a worktree whose folder has become a symlink; and `@osdlc/host-cleaner/testing` gives a plugin's tests a fake context, fake programs for the kit, a temporary home and `contractSuite`, which checks a plugin against the contract, a `delete` given its own candidate moved outside behind a symlink included, and which every shipped plugin passes; and `detect` may answer `{ active, note }`, a note the survey keeps in `notes` and `status` prints as a warning naming the plugin; and every hook's `ctx` carries `targetsGiven`, false when the command line fell back to the directory it runs in, kept in the plan; and a root may be declared `{ path, self: true }`, so the store folder itself may be a candidate, while the core leaves out with a warning a root that is `/`, is or holds the home folder, is a personal folder such as `~/Documents`, is or holds a target or a linked worktree, or is a checkout (and a self root that is a symlink), checked at the survey, right before `delete` and in `kit.remove`; and `kit.running({ name })` matches the name against the words of each process's command line, so `pnpm` under `node` and the Gradle daemon under `java` are found; and paths are compared by `realpathSync.native`, so where the filesystem ignores case `~/documents` is `~/Documents`.
