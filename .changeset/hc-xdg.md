Use the `xdg` folders on macOS as on Linux, so on macOS the config is `~/.config/host-cleaner/config.json` and receipts and the log are under `~/.local/state/host-cleaner/` (Windows keeps its own folders). A config left in `~/Library/Application Support/host-cleaner/` is not read, and a run without `--config` warns about it on stderr; move it to `~/.config/host-cleaner/`. Receipts and the log from versions up to 0.3 are not moved: they stay in `~/Library/Application Support/host-cleaner/receipts/` and `~/Library/Logs/host-cleaner/`. `host-cleaner config` prints the config file it looked for and whether it exists. Every command refuses a folder variable it cannot use, such as a non-empty `HOST_CLEANER_CONVENTION` other than `native` or `xdg` or a relative `HOST_CLEANER_CONFIG_DIR`, with exit 2. When `HOME` is unset the OS account's home is used, and `XDG_CONFIG_HOME` with `XDG_STATE_HOME` place the folders without one; with neither, a command that needs the folders exits 1, while `clean --dry-run` does not need them.
