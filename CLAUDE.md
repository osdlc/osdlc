# Working in osdlc/osdlc

- What holds for every library here: [packages/README.md](./packages/README.md).
- This repository's standards: [docs/planning/standards/](./docs/planning/standards/README.md).
  Follow them in every change.
- When you add or change a feature of a library, document it in that library
  in the same change: a short usage section in its `README.md`, and a page
  under its `docs/guide/` when it needs more than an example. See
  [S-0003](./docs/planning/standards/S-0003-document-features-as-added.md).
